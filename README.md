## ✨ 遊戲特色

### 雙模式 AI 引擎

1. **Gemini API 模式**（推薦）
   - 使用 Google Gemini 進行語意分析

## 🔑 API 金鑰設定

### 取得 Google Gemini API 金鑰

1. 前往 [Google AI Studio](https://aistudio.google.com/apikey)
2. 以 Google 帳號登入
3. 點選「Create API key」建立新金鑰
4. 複製金鑰（格式：`AIza...`）

> 免費方案不需要綁信用卡。`gemini-2.5-flash` / `gemini-2.5-flash-lite` 屬於免費方案的主力模型，本遊戲的判定請求量很低，免費額度通常綽綽有餘。

### 在遊戲中設定

1. 首次啟動遊戲時會提示設定
2. 輸入你的 API 金鑰（系統會自動清除貼上時夾帶的空白、換行等雜質）
3. 金鑰會儲存在瀏覽器本地（localStorage）
4. 系統會自動偵測這把金鑰可用的模型，無需手動指定
5. 也可以跳過設定，使用本地模式

### 注意事項

- ⚠️ **金鑰儲存位置**：金鑰僅存在你自己的瀏覽器，不會上傳到任何伺服器，也不會進入專案原始碼。
- 🖥️ **共用電腦請務必清除金鑰**：在學校公用機、教室電腦或任何共用裝置上使用時，**輸入金鑰時請取消勾選「在此裝置記住金鑰」**（金鑰只在本次瀏覽期間有效，瀏覽器關閉即清除），或在用完後到遊戲選單點「🔑 重新設定 API 金鑰 → 確定清除」。否則金鑰會留在該瀏覽器，後續使用者可能用到你的額度。也可直接使用無痕／私密視窗開啟。
- ⏳ **自動清理**：勾選「記住金鑰」時，金鑰會在 **30 天後自動清除**並要求重新輸入，避免長期殘留。
- 🔒 **金鑰安全**：請使用「你自己」的金鑰，不要把金鑰公開分享。本專案為純前端網頁，金鑰一律由使用者在網頁上輸入、只存在使用者自己的瀏覽器，**不會寫進原始碼、也不會上傳到儲存庫**。請勿將任何金鑰硬寫進前端程式碼後公開——任何人都能在瀏覽器讀到。
- 🔐 **建議限制金鑰**：可在 Google Cloud Console 將金鑰限制為僅能呼叫 Generative Language API，降低外洩時的風險。
- 🧹 **清除金鑰**：清除瀏覽器資料、或在遊戲選單點「🔑 重新設定 API 金鑰」，即可移除已儲存的金鑰。
- 🔄 **變更金鑰**：可在遊戲選單中重新設定（換金鑰時會自動清除模型快取並重新偵測）。
- 🔍 **資料用途**：免費方案的輸入內容可能被 Google 用於改善模型；若有疑慮請改用付費方案或避免輸入敏感資訊。

## 🛠️ 開發者資訊

### 修改故事內容

編輯 `story.js`，所有故事節點都在 `STORY_DATA` 物件中：

```javascript
chapter1: {
    c1_1: {
        id: 'c1_1',
        background: 'assets/scenes/教室.png',
        characters: {
            center: 'assets/characters/女大學生.png'
        },
        speaker: '旁白',
        text: '你的對話內容...',
        next: 'c1_2'
    },
    // ... 更多節點
}
```

### 調整 AI 判定規則

在 `story.js` 的 `aiChallenge` 中修改：

```javascript
aiChallenge: {
    prompt: '給玩家的提示',
    hint: '詳細的線索',
    validation: {
        positivePatterns: [
            /正面的正則表達式/,
        ],
        negativePatterns: [
            /負面的正則表達式/,
        ]
    }
}
```

### 模型選用（已自動化）

本版本**不再需要手動指定模型**。`game.js` 的 `resolveModel()` 會透過 ListModels 自動偵測金鑰可用的模型，`scoreModel()` 則依偏好挑選（`flash-lite` > `flash` > `pro`，偏好穩定版、版本越新越優先）。

若要調整偏好（例如改成優先用 `flash` 而非 `flash-lite`），編輯 `game.js` 中的 `scoreModel()` 評分權重即可。若要在 ListModels 失效時改變備用模型，編輯 `fallbackModel()` 的回傳值。

### 新增寶石類型

1. 在 `game.js` 的 `collectedGems` 新增項目
2. 在 HTML 的 gems-display 新增 slot
3. 在 CSS 新增對應樣式

## 🐛 疑難排解

### 問題：遊戲畫面一片空白

**解決方法**：
1. 確認所有檔案都在正確位置
2. 檢查瀏覽器 Console 是否有錯誤訊息
3. 使用 HTTP 伺服器而非直接開啟 HTML

### 問題：API 呼叫失敗

判定失敗時，畫面會直接顯示實際錯誤原因，可依此排查：

1. **403**：金鑰權限不足或未啟用 Generative Language API → 到 [Google AI Studio](https://aistudio.google.com/apikey) 確認金鑰
2. **404**：找不到可用模型（罕見，系統會自動重新偵測）→ 確認金鑰所屬專案有 Gemini 存取權
3. **429**：已達免費額度上限 → 稍後再試，或改用自己的金鑰
4. **400**：請求格式有誤 → 檢查網路或回報問題
5. 確認 API 金鑰格式正確（`AIza...`）
6. 仍可使用本地模式作為備用

### 問題：圖片無法顯示

**解決方法**：
1. 確認 assets 資料夾結構完整
2. 檢查圖片檔名是否與程式碼一致
3. 使用瀏覽器開發者工具查看網路請求

### 問題：存檔無法讀取

**解決方法**：
1. 確認瀏覽器允許 localStorage
2. 清除瀏覽器快取後重試
3. 檢查是否在無痕模式（無法儲存）

### 2.1
- **移除 config.js**：金鑰一律改由使用者在網頁上輸入，不再依賴設定檔。
